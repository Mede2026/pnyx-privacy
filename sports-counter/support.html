Installation

  • Où télécharger l'app ? Sur la page d'accueil, bouton « Télécharger pour Windows ». Vous obtenez l'installateur officiel de la dernière version, publié sur GitHub.
  • Windows affiche « Windows a protégé votre ordinateur ». C'est l'avertissement SmartScreen, affiché pour les applications récentes qui n'ont pas encore de réputation auprès de Microsoft. Cliquez sur Informations complémentaires, puis Exécuter quand même.
  • Quelle version de Windows ? Windows 10 ou 11. L'app utilise WebView2, le moteur d'affichage de Microsoft Edge, déjà présent sur ces versions. Il n'existe pas de version Mac.
  • Comment la mettre à jour ? Rien à faire : l'app vérifie elle-même les nouvelles versions et vous propose de les installer. Après une mise à jour, un écran résume les nouveautés.
  • Comment la désinstaller ? Paramètres → Applications → Applications installées → Sports Counter → Désinstaller.

Utilisation

  • Le widget a disparu. Appuyez sur Ctrl + Alt + S, ou relancez l'app depuis le menu Démarrer : elle réaffiche le widget au lieu de s'ouvrir en double. Son icône se trouve aussi près de l'horloge, parfois cachée derrière la petite flèche ^.
  • Comment choisir mes équipes, joueurs, pilotes ou combattants ? Clic sur l'icône près de l'horloge : la fenêtre des réglages s'ouvre. Choisissez une ligue à gauche, puis cochez vos favoris. La section Réglages regroupe les pilotes de F1, les combattants de l'UFC et les joueurs de hockey.
  • Je ne reçois pas de notifications. Vérifiez qu'elles sont activées dans Réglages → Notifications, et que l'app est ouverte (son icône est près de l'horloge). Pendant un jeu ou une vidéo en plein écran, elles sont masquées si l'option « Cacher en plein écran » est active.
  • Le widget cache ma fenêtre. Dans Réglages, choisissez « Sur le bureau » : le widget reste derrière vos fenêtres. Vous pouvez aussi réduire sa taille, ou le faire apparaître seulement pendant un match.
  • Le widget dit « vérifie ta connexion Internet ». L'app n'arrive pas à joindre ESPN. Elle garde les derniers scores connus et réessaie toute seule dès que le réseau revient.
  • Certains textes sont encore en anglais. Les descriptions des jeux sont traduites par Google Traduction, en quelques secondes. Si la traduction n'est pas disponible, le texte reste en anglais. La traduction se désactive dans Réglages.
  • Une information manque ou semble fausse. Les données viennent d'ESPN. Quand ESPN ne fournit pas une information (les 3 étoiles, les chances de victoire…), la section ne s'affiche simplement pas.
  • Raccourcis clavier. Ctrl + Alt + S affiche ou cache le widget, Ctrl + Alt + M ouvre la fenêtre Match. Les deux se changent dans Réglages.
