Scanner

  • Où est le bouton pour scanner ? Il n'y en a pas : pointez la caméra vers le code, il est lu dès qu'il entre dans le champ. Aucune photo n'est prise.
  • La caméra reste noire. Autorisez QR Studio dans Réglages › Confidentialité et sécurité › Caméra. En attendant, « Scanner une photo » lit un code dans une image de votre photothèque.
  • Un lien s'ouvre tout seul. C'est l'ouverture automatique des liens web, avec une bannière de 1,5 seconde et un bouton Annuler. Choisissez « Jamais » dans Réglages › Scanner › Ouvrir automatiquement. Les réseaux Wi-Fi, contacts, événements et paiements demandent toujours une confirmation.
  • Scanner beaucoup de produits de suite. Choisissez Lot en haut du scanner : les codes s'empilent avec leur quantité, puis s'enregistrent dans un dossier ou s'exportent en CSV.
  • Un code mal éclairé. Touchez la lampe ; une fois allumée, elle propose trois intensités.

Créer des codes

  • « Illisible » s'affiche sous mon code. Le style choisi empêche sa lecture : augmentez le contraste, gardez des modules plus foncés que le fond, ou réduisez le logo. L'app relit chaque code avant de le proposer.
  • Mon texte est trop long. Un code a une capacité maximale. Raccourcissez le contenu, ou mettez-le sur une page web et encodez son lien.
  • Imprimer ou partager un code. Dans le détail du code, le bouton Partager propose PNG, JPEG, PDF vectoriel ou SVG, jusqu'à 2048 pixels, ainsi que l'impression.

Synchronisation et sauvegarde

  • Mes codes n'apparaissent pas sur mon autre appareil. Vérifiez que les deux appareils utilisent le même compte iCloud et que Réglages › iCloud est activé dans QR Studio. La synchronisation peut prendre quelques minutes.
  • Faire une sauvegarde. Réglages › Sauvegarde crée un fichier .json unique, à enregistrer où vous voulez. À la restauration, choisissez Fusionner ou Remplacer.
  • Supprimé par erreur. Les codes supprimés restent 30 jours dans « Supprimés récemment ».

Apple Watch

  • Afficher ma carte de fidélité sur la montre. Dans le détail du code sur l'iPhone, activez « Code principal sur l'Apple Watch ». Ajoutez ensuite la complication QR Studio à votre cadran.
  • « Ce code est trop dense ». Au-delà d'environ 300 caractères, un code n'est plus lisible sur un écran de montre. Affichez-le sur l'iPhone.

Envoyer les scans vers le Mac

  • Appairer. Sur le Mac, ouvrez QR Studio › Réglages › iPhone, puis scannez le code affiché avec l'iPhone.
  • Activer l'envoi. Quand le Mac est sur le même réseau, une puce apparaît en haut du scanner de l'iPhone. Touchez-la : le point devient vert.
  • La frappe automatique ne tape rien. macOS demande l'autorisation Accessibilité : Réglages Système › Confidentialité et sécurité › Accessibilité, puis cochez QR Studio.
  • Raccourcis sur Mac. ⌘ N nouveau code, ⌘ K scanner, ⌘ O ouvrir une image, ⌘ F rechercher, ⌘ S exporter.

Sécurité des liens

  • Vérifier les liens avec Google Safe Browsing. Activez l'option dans Réglages › Réseau. Un lien signalé affiche un écran rouge avant toute ouverture. La protection n'est pas parfaite : elle peut signaler un site sûr ou laisser passer un site dangereux.
  • « Caractères trompeurs » ou « lien raccourci ». L'adresse imite peut-être un autre site, ou cache sa vraie destination. Vérifiez le domaine affiché en gros avant d'ouvrir.

Siri et Raccourcis

  • « Scanne un code avec QR Studio », « Crée un QR avec QR Studio », « Montre mon code Wi-Fi dans QR Studio », « Quel était mon dernier scan dans QR Studio ».
